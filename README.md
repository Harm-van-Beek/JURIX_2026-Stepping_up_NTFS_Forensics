# Introduction

This repository contains supplementary material for the following submission:

Lorenz Hornung, Jesse Heyninck, and Harm van Beek, *Stepping up NTFS Forensics: Computing Normal NTFS Timestamp Structures.*

# Content

The supplementary material consists of the following:

- **Extended version of the paper:** Includes proofs omitted from the published paper. When citing this work, please cite only the published paper, not the extended version.

- **Implementation:** Code to (i) computationally identify normal NTFS timestamp structures and (ii) assess their prevalence across disk images.
